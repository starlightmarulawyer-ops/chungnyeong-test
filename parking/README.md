# 주차 위치

주차한 곳을 체크하고 사진으로 남겨 두는 휴대폰용 앱입니다.
앱을 열면 맨 위에 **‘지금 내 차는’** 카드가 크게 보여서, 어디에 세웠는지 바로 알 수 있습니다.
서버나 데이터베이스 없이 이 폴더의 파일만으로 동작합니다.

## 할 수 있는 일

| 장소 | 고르는 방법 |
| --- | --- |
| **집** | 지하주차장(1곳) 또는 야외주차장(101동 앞 ~ 107동 앞, 정문 쪽, 관리사무소 앞) 중 하나를 체크 |
| **사무실** | B1(지하 1층) ~ B4(지하 4층) 중 하나를 체크 |
| **외부** | 장소 이름을 짧게 적기 (예: 세종시청 지하 2층 C구역). 한 번 적은 곳은 ‘최근에 주차한 곳’ 버튼으로 다시 고를 수 있음 |

- **사진**: ‘사진 찍기’를 누르면 바로 카메라가 열립니다. 이미 찍어 둔 사진은 ‘앨범에서 고르기’로 넣습니다. 사진은 선택 사항입니다.
- **저장**: ‘여기 주차했어요’를 누르면 저장되고, 화면 맨 위 카드가 바뀝니다. 잘못 눌렀다면 아래에 뜨는 ‘되돌리기’를 6초 안에 누르세요.
- **주차 기록**: 날짜별로 쌓입니다. 오른쪽 × 버튼으로 지울 수 있고, 지운 직후 ‘되돌리기’로 복구할 수 있습니다.
- **인터넷이 안 터지는 곳**(지하주차장 등)에서도 열립니다. 아래 ‘휴대폰에 설치하기’대로 인터넷 주소로 한 번 열어 둔 경우에 해당합니다.
- 휴대폰의 어두운 화면(다크 모드) 설정도 따라갑니다.

## 사진은 얼마나, 언제까지 남나요

- 휴대폰 카메라 사진(보통 3~5MB)을 긴 변 1280px로 줄여 저장합니다. 한 장에 대략 0.1~0.3MB입니다.
- **오늘 찍은 사진**과 **지금 주차 위치(가장 최근 기록)의 사진**만 남기고, 나머지는 다음에 앱을 열 때 자동으로 지웁니다.
  - 예: 어젯밤 집에 세우며 찍은 사진은, 오늘 아침 다른 곳에 주차를 기록하기 전까지 그대로 남습니다.
- 사진이 지워져도 **체크한 기록(언제, 어디)은 계속 남습니다.** 기록은 최근 300건까지 보관합니다.

## 휴대폰에 설치하기 (처음 한 번)

이 앱을 휴대폰에서 쓰려면 인터넷 주소가 필요합니다. 이 저장소는 공개(public) 저장소라서 GitHub Pages로 무료로 주소를 만들 수 있습니다.

1. 이 변경 사항이 `main` 브랜치에 합쳐진 뒤, GitHub 저장소 페이지에서 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `/ (root)`로 고르고 **Save**를 누릅니다.
3. 몇 분 뒤 아래 주소가 열립니다.
   `https://starlightmarulawyer-ops.github.io/chungnyeong-test/parking/`
4. 휴대폰에서 그 주소를 열고 홈 화면에 추가합니다.
   - **아이폰**: 사파리로 열기 → 아래쪽 공유 버튼 → ‘홈 화면에 추가’
   - **안드로이드**: 크롬으로 열기 → 오른쪽 위 ⋮ → ‘홈 화면에 추가’ 또는 ‘앱 설치’
5. 이제 홈 화면의 파란 **P** 아이콘으로 엽니다.

## 꼭 알아 두실 점

- 기록과 사진은 **그 휴대폰의 브라우저 안에만** 저장됩니다. 다른 휴대폰이나 PC와는 공유되지 않고, 어디로도 전송되지 않습니다.
- **아이폰은 꼭 ‘홈 화면에 추가’해서 쓰세요.** 사파리 탭으로만 쓰면, 7일 넘게 열지 않았을 때 사파리가 저장된 기록을 지울 수 있습니다.
- 브라우저의 ‘방문 기록 및 웹사이트 데이터 지우기’를 하면 주차 기록도 함께 지워집니다.
- 앱을 고친 새 버전은 **다음에 열 때** 적용됩니다. 새 버전이 안 보이면 앱을 완전히 닫았다가 다시 열어 주세요.
- 집 야외주차장 이름은 세종시 연서면 대원네스트빌(101~107동)을 기준으로, 동 번호와 정문·관리사무소를 써서 만들었습니다. 단지 배치도까지는 확인하지 못했으니, 실제로 부르는 이름과 다르면 아래처럼 바꿔 주세요.

## 선택지 이름 바꾸기 (개발자용)

`index.html`의 스크립트 맨 위에 있는 두 목록만 고치면 됩니다.

```js
const HOME_OUTDOOR_SPOTS = ['101동 앞', '102동 앞', /* … */ '관리사무소 앞'];
const OFFICE_FLOORS = [['B1', '지하 1층'], ['B2', '지하 2층'], ['B3', '지하 3층'], ['B4', '지하 4층']];
```

앱 파일을 고친 뒤에는 `sw.js`의 `CACHE = 'parking-v1'` 숫자를 하나 올려 주세요(`parking-v2`). 그래야 이미 설치한 휴대폰이 새 파일로 바꿉니다.
지난 기록에는 저장할 때의 이름이 그대로 남으므로, 이름을 바꿔도 예전 기록이 깨지지 않습니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 앱 전부 (화면, 디자인, 동작) |
| `sw.js` | 인터넷이 끊겨도 앱이 열리도록 화면 파일을 휴대폰에 보관 |
| `manifest.webmanifest` | 홈 화면에 추가할 때의 이름·아이콘 |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |
